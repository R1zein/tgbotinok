# Telegram-бот помощник

Многофункциональный бот на **aiogram 3** + **SQLite**. Любую функцию можно выключить:
глобально (админ бота, `/admin`), для группы (`/settings`) или лично (меню бизнес-ассистента).

## Режимы

### 1. Чат-менеджер в группах
Команды работают с префиксом `/`, `!`, `.` или без него (`мут`, `/mute`, `!мут`).

| Раздел | Команды |
|---|---|
| Модерация (админы, ответом или `@юзернейм`/ID) | `мут 30m причина`, `размут`, `бан 1d`, `разбан`, `кик`, `варн`, `снять варн`, `варны` |
| Калл | `калл текст` / `call` — пингует всех участников, которых бот видел в чате |
| Экономика | `баланс`, `бонус` (раз в сутки), `передать 100`, `топ` |
| Казино | `казино 100`, `слоты 100` 🎰, `кости 100` 🎲, `дартс` 🎯, `баскет` 🏀, `футбол` ⚽, `боулинг` 🎳 (`все` — всё сразу, `1к` = 1000) |
| Дуэли | `дуэль 100`, `кнб [ставка]` — ответом (вызов игрока) или открытый вызов |
| Мини-игры | `крестики`, `угадай`, `монетка`, `шар вопрос`, `инфа текст`, `кто сегодня …`, `выбери A или B` |
| RP | `обнять`, `поцеловать`, `ударить`, `дать пять` … (ответом), `рп` — список |
| Браки | `брак`, `развод`, `мой брак`, `браки` |
| Настольные | `шахматы`, `шашки` (русские правила: обязательное взятие, дамки, серия взятий) |

Время: `s/m/h/d/w` или `с/м/ч/д/н`, без времени — навсегда. Лимит варнов (2–10) и наказание
(мут на сутки / кик / бан) настраиваются в `/settings`.

### 2. Бизнес-ассистент (Telegram Premium)
Пользователь подключает бота: *Настройки → Telegram для бизнеса → Чат-боты*.
- уведомления в ЛС бота: **изменённые** сообщения (было → стало) и **удалённые** (текст + медиа);
- **исчезающие** фото/видео/голосовые/кружки: ответьте на них — копия придёт в ЛС бота;
- `.мут` / `.mute` — сообщения собеседника сразу удаляются у обоих, в чате появляется
  «🔇 Пользователь заглушен» с кнопкой «Размутить» (нажать может только владелец);
  `.размут` / `.unmute` — снять;
- `.шахматы` / `.chess`, `.шашки` / `.checkers` — партия с собеседником прямо в ЛС.

### 3. Отслеживание улучшенных подарков
Кнопка «🎁 Подарки» → включить. Бот присылает каждый новый улучшенный подарок: коллекция и номер,
модель/фон/узор с редкостью, кто улучшил, ссылка `t.me/nft/…`. Можно выбрать только нужные коллекции.

### 4. Отслеживание юзернеймов
Кнопка «🔎 Юзернеймы» → добавить один или несколько (`@name`, `t.me/name`). Когда юзернейм
освободится (или появится на Fragment) — придёт уведомление. Лимит — `MAX_USERNAMES`.

## Быстрая установка на сервер (удобно с телефона)

```bash
git clone -b claude/telegram-bot-helper-modules-pabn9i https://github.com/R1zein/tgbotinok.git
cd tgbotinok
bash setup.sh
```
Скрипт сам поставит Docker, спросит токен, ваш ID и данные юзербота, выполнит вход в аккаунт
и запустит бота. Повторный запуск `bash setup.sh` позволяет поменять настройки.

## Установка

1. **@BotFather**:
   - создайте бота, токен → `BOT_TOKEN`;
   - *Bot Settings → Business Mode → Turn on* (для бизнес-режима);
   - *Bot Settings → Group Privacy → Turn off* — чтобы бот видел команды без `/`
     (если бот администратор группы, он и так видит все сообщения).
2. **Юзербот** (нужен для подарков и юзернеймов; лучше отдельный технический аккаунт):
   - получите `API_ID` и `API_HASH` на <https://my.telegram.org> → *API development tools*;
   - `python -m bot.services.login` → строку сессии вставьте в `USERBOT_SESSION`.
3. Конфигурация: `cp .env.example .env` и заполните (`ADMIN_IDS` — ваш Telegram ID).
4. Запуск:
   ```bash
   python -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt
   python -m bot
   ```
   или через Docker: `docker compose up -d --build` (база хранится в `./data`).

В группе выдайте боту права администратора: удаление сообщений и блокировка участников.

## Как это устроено

- `bot/handlers/` — обработчики (группы, бизнес, меню, админка); `bot/games/` — движки
  шахмат (python-chess), шашек и крестиков-ноликов; `bot/services/` — юзербот и фоновые
  наблюдатели; `bot/db.py` — SQLite-схема и запросы.
- **Подарки**: номера уникальных подарков в коллекции выдаются по порядку, поэтому для каждой
  коллекции хранится последний номер и юзербот запрашивает следующий
  (`payments.getUniqueStarGift("<Коллекция>-<N>")`). Опрашиваются только коллекции, на которые
  кто-то подписан.
- **Юзернеймы**: быстрая проверка страницы `t.me/<name>` + подтверждение через
  `account.checkUsername` (свободен / занят / продаётся на Fragment). Запросы юзербота идут
  с паузой `USERBOT_MIN_DELAY`, FloodWait обрабатывается автоматически.
- **Калл**: Bot API не отдаёт полный список участников, поэтому бот пингует тех, кого видел
  (писали в чат или вступали, пока бот был в группе). Кулдаун — 5 минут (кроме админов).
- **Бизнес-кэш**: входящие сообщения хранятся `BUSINESS_CACHE_DAYS` дней — иначе после удаления
  нечего было бы показать.
