# Telegram-бот помощник

Многофункциональный бот на **aiogram 3** + **SQLite**. Любую функцию можно выключить:
глобально (админ бота, `/admin`), для группы (`/settings`) или лично (меню «Ассистент чатов»).

## Режимы

### 1. Ассистент групп
Команды работают с префиксом `/`, `!`, `.` или без него (`мут`, `/mute`, `!мут`).

| Раздел | Команды |
|---|---|
| Модерация (админы, ответом или `@юзернейм`/ID) | `мут 30m причина`, `размут`/`анмут`, `бан 1d`, `разбан`, `кик`, `варн`, `снять варн`, `варны` |
| Калл | `калл текст` / `call` — пингует всех участников, которых бот видел в чате |
| Экономика | `баланс`, `бонус` (раз в сутки), `передать 100`, `топ` |
| Заработок | `работа` (раз в час), `копать` (раз в 10 мин, иногда редкая находка), `пособие` (если на счету < 100) |
| Автоотметки | в `/settings` включить «🏷 Автоотметки» и пройти мастер имён; бот отмечает человека, когда его имя пишут в любом падеже. `ники`, `ник паша` (ответом), `забыть ник паша` |
| ИИ-ответы | включить в `/settings` («🤖 ИИ-ответы», характер — обычный/дерзкий/милый/краткий/🦎 адаптивный: копирует стиль собеседника, запоминает его и подкалывает жёстче). Бот отвечает на `ии …`, `бот …`, своё имя (`esg …`, задаётся `AI_NAME`), упоминание `@бот` или ответ на его сообщение, учитывая последние ~30 сообщений чата. Нужен `DEEPSEEK_API_KEY` в `.env` |
| ИИ сам в чате | в `/settings` (блок ИИ): «🤖 ИИ вступает в разговор сам» — бот читает каждое сообщение (частоту можно ограничить: раз в 5–60 сек) и отвечает, только когда считает нужным; «🤖 ИИ наказывает за оскорбления» — варн или мут 5–60 мин за явное оскорбление бота или создателя (шутки и критику не трогает; создателя и админов не наказывает; лимит варнов — как в настройках) |
| Голосовые | `текст` ответом на голосовое/кружок — расшифровка (Whisper). ИИ отвечает и на голосовые: в ответ на его сообщение или с подписью `ии`. В личке с ботом — просто пришлите голосовое; в ЛС с людьми — `.текст` ответом |
| Реакции | ИИ, отвечая, ставит реакцию на сообщение по его эмоции (наезд → 🤡/🗿, похвала → ❤, шутка → 🤣…). Авто-реакции на обычные сообщения в `/settings` (частота 5–100%): эмоцию определяет ИИ, без ключа ИИ — по ключевым словам. `реакция 🔥` ответом — поставить вручную. Только стандартные реакции Telegram (💀 боту недоступен) |
| Казино | `казино 100`, `слоты 100` 🎰, `кости 100` 🎲, `дартс` 🎯, `баскет` 🏀, `футбол` ⚽, `боулинг` 🎳 (`все` — всё сразу, `1к` = 1000) |
| Дуэли | `дуэль 100`, `кнб [ставка]` — ответом (вызов игрока) или открытый вызов |
| Мини-игры | `крестики`, `угадай`, `монетка`, `шар вопрос`, `инфа текст`, `кто сегодня …`, `выбери A или B` |
| RP | `обнять`, `поцеловать`, `ударить`, `дать пять` … (ответом), `рп` — список |
| Браки | `брак`, `развод`, `мой брак`, `браки` |
| Настольные | `шахматы`, `шашки` (русские правила: обязательное взятие, дамки, серия взятий) |

Время: `s/m/h/d/w` или `с/м/ч/д/н`, без времени — навсегда. `команды` — список команд прямо в группе. Лимит варнов (2–10) и наказание
(мут на сутки / кик / бан) настраиваются в `/settings`.

Администраторы с правом ограничения участников могут просить модерацию обычным текстом:
`бот, выдай варн @user за флуд`, `esg выпиши ему варн за оскорбление` (ответом на участника),
`бот, замути @user на 10 минут за флуд`. Вместо «бот» можно написать имя бота или его
`@юзернейм`. Это выполняемые команды с проверкой прав, они работают и без ИИ.

### 2. Ассистент чатов
Пользователь подключает бота к своему аккаунту: *Настройки → Telegram для бизнеса → Чат-боты*.
- уведомления в ЛС бота: **изменённые** сообщения (было → стало) и **удалённые** (текст + медиа);
- правки и удаления, сделанные ботом собеседника (его команды вроде `.команды`,
  «пикми»-правки в первые секунды после отправки), не присылаются;
- **исчезающие** фото/видео/голосовые/кружки: ответьте на них — копия придёт в ЛС бота;
- `.мут` / `.mute` — сообщения собеседника сразу удаляются у обоих, в чате появляется
  «🔇 Пользователь заглушен» с кнопкой «Размутить» (нажать может только владелец);
  `.размут` / `.unmute` — снять;
- `.шахматы` / `.chess`, `.шашки` / `.checkers` — партия с собеседником прямо в ЛС.
- `.клон` — бот повторяет от вашего имени каждое сообщение собеседника в этом чате
  (ещё раз `.клон` — выключить); `.спам текст 5` — отправить текст до 10 раз;
- **режимы текста** — командой прямо в чате (действуют только в нём): `.пикми` (kawaii), `.гопник`, `.пират`, `.боярин`,
  `.капс`, `.шепот`, `.заборчик`, `.наоборот`, `.робот`, `.проклятый`, `.эмодзи`, `.разрядка`.
  Бот сразу переписывает ваши сообщения; повтор команды выключает, `.обычный` — выключить;
- **формат текста** (как в TonzBot) — в меню бота: 💬 Ассистент чатов → 🔤 Формат текста
  (жирный, курсив, подчёркнутый, зачёркнутый, моно, спойлер, цитата);
- `.команды` — список всех команд прямо в чате (сообщение исчезнет через минуту).

### 3. Отслеживание улучшенных подарков
Кнопка «🎁 Подарки» → включить. Бот присылает каждый новый улучшенный подарок: коллекция и номер,
модель/фон/узор с редкостью, кто улучшил, ссылка `t.me/nft/…`. Можно выбрать только нужные коллекции,
а также фильтры по **фону** (общие для всех коллекций) и **узору** (свои у каждой коллекции) —
списки отсортированы от редких к частым.

### 3б. Выгодные лоты маркета Telegram
🎁 Подарки → 💸 Выгодные лоты маркета. Бот смотрит новые лоты официального маркета и присылает те,
что дешевле **следующего похожего лота** минимум на выбранный процент (10–50%). Если выбран фильтр
по фону — сравнение с лотами того же фона (модель не важна), иначе — с лотами той же модели.
Настройки: валюта (любая / звёзды / TON), коллекции, фильтры по фону и узору. Это оценка «ниже
рынка», а не гарантия выгоды. Первый проход только запоминает текущие лоты, уведомления — о новых.

### 4. Отслеживание юзернеймов
Кнопка «🔎 Юзернеймы» → добавить один или несколько (`@name`, `t.me/name`). Когда юзернейм
освободится (или появится на Fragment) — придёт уведомление. Лимит — `MAX_USERNAMES`.

## Быстрая установка на сервер (удобно с телефона)

```bash
git clone -b claude/telegram-bot-helper-modules-pabn9i https://github.com/R1zein/tgbotinok.git
cd tgbotinok
bash setup.sh
```
Скрипт сам поставит Docker, спросит токен, ваш ID и данные юзербота, выполнит вход в аккаунт
и запустит бота. Повторный запуск `bash setup.sh` позволяет поменять настройки.

## Установка

1. **@BotFather**:
   - создайте бота, токен → `BOT_TOKEN`;
   - *Bot Settings → Business Mode → Turn on* (нужно для ассистента чатов);
   - *Bot Settings → Group Privacy → Turn off* — чтобы бот видел команды без `/`
     (если бот администратор группы, он и так видит все сообщения).
2. **Юзербот** (нужен для подарков и юзернеймов; лучше отдельный технический аккаунт):
   - получите `API_ID` и `API_HASH` на <https://my.telegram.org> → *API development tools*;
   - `python -m bot.services.login` → строку сессии вставьте в `USERBOT_SESSION`.
3. Конфигурация: `cp .env.example .env` и заполните (`ADMIN_IDS` — ваш Telegram ID).
4. Запуск:
   ```bash
   python -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt
   python -m bot
   ```
   или через Docker: `docker compose up -d --build` (база хранится в `./data`).

В группе выдайте боту права администратора: удаление сообщений и блокировка участников.

## Расшифровка голосовых
По умолчанию работает **Whisper прямо на сервере** (`STT_BACKEND=local`, библиотека faster-whisper):
бесплатно и без ключей. При первом голосовом бот скачает модель в `data/whisper` (base ≈ 150 МБ).
Модель `base` на 1 ядре расшифровывает ~30 сек речи примерно за 5–15 сек; `small` точнее, но в
2–3 раза медленнее. Можно вместо этого использовать API (`STT_BACKEND=api`, OpenAI или Groq).

## Обновление без захода на сервер
Один раз включите автообновление (или ответьте `y` на вопрос в `bash setup.sh`):
```bash
cd ~/tgbotinok && git pull && bash scripts/autoupdate.sh --install
```
Сервер раз в 5 минут проверяет GitHub и, если есть новые коммиты, сам делает `git pull` и
пересобирает бота. Журнал — `data/autoupdate.log`, выключить — `bash scripts/autoupdate.sh --remove`.
После первоначальной настройки достаточно отправлять изменения в отслеживаемую сервером
ветку GitHub. Скрипт сначала собирает образ, затем запускает контейнер; неудачная сборка
повторяется при следующей проверке. Локальные изменения и разошедшаяся история блокируют
обновление, чтобы не затереть правки на сервере. Первая проверка пересобирает текущую версию.
Сообщение «готово» означает успешное выполнение Docker Compose; работоспособность внешних
подключений Telegram и ИИ следует проверять по журналу бота.

ИИ-варны и муты содержат отдельную строку с причиной и цитату исходного сообщения.
Сложные случаи в текстах и подписях проверяются отдельным запросом модератору до обычного ответа,
независимо от характера ИИ и паузы между ответами. Учитываются @упоминания, упоминания
по Telegram ID и ответы на сообщения бота или создателей из `ADMIN_IDS`. Имена создателей
берутся также из участников группы, даже если они не писали боту в личку.
Нужны включённые «ИИ-ответы» и «ИИ наказывает за оскорбления» в `/settings`, доступный
ключ ИИ и права ограничения участников для мутов. Создатели и админы группы освобождены
от автоматических наказаний. Отдельная проверка расходует лимит ИИ-запросов; её ошибки
и решения записываются в журнал приложения (`docker compose logs --tail=100 bot`).
Короткие однозначные прямые оскорбления (`@бот иди нахуй`, `бот ты дебил`, `иди нахуй`
ответом боту/создателю) дают варн по точному правилу до обращения к ИИ; для них ключ ИИ
не требуется. Правило проверяет фразу целиком: цитаты, отрицания и другой адресат не
являются автоматическим поводом для варна. Лимит варнов и последующее наказание — из
настроек группы. При неудачном наказании по лимиту предупреждения не сбрасываются.
Команда администратора `/aistatus` показывает версию модерации, активные настройки,
наличие ключа и прав для мута и результат последней проверки после запуска.
Её можно отправить ответом на спорное сообщение, чтобы проверить, освобождён ли автор
от автоматических наказаний. Команда не пересматривает старое сообщение и не наказывает.
В режиме «ИИ вступает в разговор сам» посторонние сообщения не передаются разговорному
ИИ: допускаются только упоминания собственного имени/ника и ответы боту. Реплика в
ответ другому участнику не вызывает ответ бота без его явного @упоминания.
Прямые адресные оскорбления не исключаются из модерации только из-за смайликов или слова
«шучу»; критика работы, мат без адресного оскорбления и обсуждение чужих цитат не наказываются.
Решение принимает языковая модель, поэтому безошибочная классификация не гарантируется.

## Как это устроено

- `bot/handlers/` — обработчики (группы, бизнес, меню, админка); `bot/games/` — движки
  шахмат (python-chess), шашек и крестиков-ноликов; `bot/services/` — юзербот и фоновые
  наблюдатели; `bot/db.py` — SQLite-схема и запросы.
- **Подарки**: номера уникальных подарков в коллекции выдаются по порядку, поэтому для каждой
  коллекции хранится последний номер и юзербот запрашивает следующий
  (`payments.getUniqueStarGift("<Коллекция>-<N>")`). Опрашиваются только коллекции, на которые
  кто-то подписан.
- **Юзернеймы**: быстрая проверка страницы `t.me/<name>` + подтверждение через
  `account.checkUsername` (свободен / занят / продаётся на Fragment). Запросы юзербота идут
  с паузой `USERBOT_MIN_DELAY`, FloodWait обрабатывается автоматически.
- **Калл**: если настроен юзербот, он сам заходит в группу (по одноразовой ссылке от бота-админа)
  и берёт полный список участников. Без юзербота — админы + все, кого бот видел в чате.
  Люди с юзернеймом отмечаются через `@`, без него — ссылкой. Кулдаун — 5 минут (кроме админов).
- **Бизнес-кэш**: входящие сообщения хранятся `BUSINESS_CACHE_DAYS` дней — иначе после удаления
  нечего было бы показать.
